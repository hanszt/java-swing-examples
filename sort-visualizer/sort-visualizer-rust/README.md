# Sorting visualizer in Rust

---

A small project to visualize sorting algorithms.

---

## Run

```sh
cargo build
./target/debug/sort-visualizer-rust
```

---

## Test

```sh
cargo test
```

---

## Clean

```sh
cargo clean
```
